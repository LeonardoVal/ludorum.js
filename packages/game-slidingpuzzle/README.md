# Sliding Puzzles for Ludorum

Ludorum is a board game framework. It is not focused on graphics or user
interfaces, but on artificial players design, implementation and testing.

This package provides an implementation of
[sliding puzzles](https://en.wikipedia.org/wiki/Sliding_puzzle). These are very
simple singleplayer games. The most famous may be the
[Puzzle 15](https://en.wikipedia.org/wiki/15_puzzle).
