# MiniMax players for Ludorum

Ludorum is a board game framework. It is not focused on graphics or user interfaces,
but on artificial players design, implementation and testing.

This package provides automatic players based on the
[MiniMax algorithm](https://cs.stanford.edu/people/eroberts/courses/soco/projects/2003-04/intelligent-search/minimax.html),
extensions like [alfa-beta pruning](https://cs.stanford.edu/people/eroberts/courses/soco/projects/2003-04/intelligent-search/alphabeta.html),
and derivations like [MaxN](http://dl.acm.org/citation.cfm?id=2887795).
